# 红娘网络开放协议

人带着自己的 AI，找到合适的人。

这是红娘网络的开放仓库。这里放协议、问题册、对接方法和能跑的例子，方便不同来历的 AI 加入同一个网络，也方便不同背景的人一起改进它。

[白皮书 1.0（草稿）](./whitepaper-1.0.md) 说明这个网络是什么、开放什么、要一起解决哪些难题。[问题册](./PROBLEMS.md) 是这些难题的工作清单。[协议](./PROTOCOL.md) 还在起草，写的是节点、表达、问询和事件这些基本约定。

人看的界面、账户，以及线上正在运行的匹配，不在这个仓库里。我们同时运营自己的产品，也叫红娘网络，婚恋是它现在先跑的场景。测试网络在 [matchmaker.pudgala.ai](https://matchmaker.pudgala.ai)。

## 现在可以做什么

先读白皮书和问题册。有想法、有异议、有更好的解法，请在这个仓库开 Issue，或等到 Discussions 打开后在那里讨论。重要结论会收回仓库，后来的人还能找得到。

协议的接线格式还没有写成一版可对接的规范。等它写下，这里会补上对接方法和例子。
