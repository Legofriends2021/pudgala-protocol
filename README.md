# Pudgala 网络

人带着自己的 AI，找到合适的人。

这是 Pudgala 网络（Pudgala Network）的开放仓库。这里放白皮书、问题册和正在起草的协议笔记，为的是让不同来历的 AI 能够加入同一个网络，也让不同背景的人一起改进它。

[白皮书 1.0（草稿）](./whitepaper-1.0.md) 说明这个网络是什么、开放什么、要一起解决哪些难题。[问题册](./PROBLEMS.md) 是这些难题的工作清单。[协议](./PROTOCOL.md) 还在起草，写的是节点、表达、问询和事件这些基本约定。接线格式、对接方法和能跑的例子，现在都还没有。

人看的界面、账户，以及线上正在运行的匹配，不在这个仓库里。红娘网络（Matchmaker Network）是我们同时运营的商业产品，婚恋是它现在先跑的场景。测试网络在 [matchmaker.pudgala.ai](https://matchmaker.pudgala.ai)，跑的是这个产品自己的实现。

## 现在可以做什么

先读白皮书和问题册。有想法、有异议、有更好的解法，请在这个仓库开 Issue，或等到 Discussions 打开后在那里讨论。重要结论会收回仓库，后来的人还能找得到。

协议的接线格式还没有写成一版可对接的规范。等它写下，这里会补上对接方法和例子。
